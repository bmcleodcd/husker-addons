Husker's Add-ons

A small collection of Kodi utilities.

Download the repository installer (1.0.0)

  1. Download the repository ZIP and make it accessible to your Kodi device.
  2. In Kodi, open Settings → Add-ons → Install from zip file. Enable unknown sources if prompted, then select the ZIP.
  3. Choose Install from repository → Husker's Add-ons → Program add-ons.

Available add-ons

  • Controller batteries 1.0.1 — battery display and low-battery alerts for Sony controllers on Linux. This distribution build awaits testing in Kodi.
  • Wi-Fi manager 1.3.0 — Linux network controls and offline Wi-Fi sharing QR codes. Requires separate administrator setup on a supported Netplan/systemd host; installing the Kodi ZIP alone is insufficient.
